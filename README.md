# 🎙️ Interview Copilot Suite

**Real-time AI copilot, stealth transcription, and dynamic technical interview assistant.**

---

## 🚀 Overview

Interview Copilot is designed to assist technical candidates and interviewers with real-time question analysis, codebase context retrieval, and low-latency speech-to-text inference:

- **Loopback Audio Listener**: Captures system audio streams in real-time.
- **Contextual Knowledge Engine**: Semantic querying against indexed technical domains.
- **Stealth Architecture**: Minimal footprint overlay and unobtrusive CLI telemetry.

---

## 🛠️ Tech Stack

- **Core**: Python 3.11+, PyAudio, WebSockets, asyncio
- **LLM Engine**: Local and API-based low-latency streaming endpoints
